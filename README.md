## The entry

`main.py` (stdlib-only Python, no third-party imports) writes a single roast
line to `entry.txt` in the output directory the harness provides through
`MAKEFUN_OUTPUT_DIR` (or `/output` by default):

> My agent marks a job done the second the shell exits 0 — the output could scream FAILED in all caps and it would still file it under 'verified'.

## Run it

```sh
python3 main.py
```

Deterministic: repeated runs produce byte-identical output.
